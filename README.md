# 英国银行合规英语强化训练 · UK Compliance English

> 42 天系统性英语强化 —— 面向赴英从事**银行业法律合规**工作的实战型训练。
> 每日 100 词（30 精讲 + 70 拓展），单文件 HTML 课程页，浏览器直接打开即用。

---

## 这是什么

一套**自建**的合规英语训练系统，覆盖：

- **专业合规英语**：AML/KYC、制裁与出口管制、金融犯罪与执法、英美监管、产品与市场工具
- **英式语音与听说**：36 段可朗读文本 + 211 条发音要点 + en-GB 朗读按钮
- **Anki 词库**：23 个领域、1932 条，与每日课程**严格按行号对齐**
- **每日课程页**：Day-01 ~ Day-42，单文件、零依赖、可离线

## 快速开始

1. 打开 `00-作战中心.html` —— 总入口（42 天计划 / 词库闪卡 / 写作模板 / 打卡）

> 所有页面均为单文件 HTML，**双击即可用**，无需服务器、无需联网。

## 核心机制：唯一真相源 = 词表顺序

每天 100 词的取材顺序，与 Anki 发放新卡的顺序**完全一致**：

```
Day-N 的 Anki 批次  =  词表第 100(N−1)+1 … 100N 行
Anki card position  =  词表行号 − 100
```

这条规则是整个系统可复现的原因。校验方法：取 Anki 下一批新卡与页面词表做**集合比对，差集必须为空**。

## 构建 / 维护

所有页面由脚本生成，**不要手改生成物**。

```bash
cd _词库源文件
node _build_dayNN.js        # 注入当日词表 + 生成 CSV + 7 项校验
node _verify_dayNN.js       # 7 区块复核（含与 Anki 队列交叉校验）

cd ../_朗读源文件
node _build.js              # 由分片重建 03 朗读库
node _build_day_pron.js     # 把当日 3 段朗读注入 Day-NN 页面（幂等）
node _chk_points.js         # 检查要点字段是否误用标记字符
```

新增一天课程：复制上一天的 HTML 作为骨架 → 在 `_词库源文件/_dayN_parts/` 写 6 个内容块 → 跑 `_build_dayNN_page.js` → 跑 `_build_dayNN.js` → 更新 `_schedule.js` 并注入朗读 → 同步作战中心与前一日页面。

## 数据的隐私边界

- 仓库**不含** Anki 数据库与备份快照（`.gitignore` 已排除），因为 revlog 记录了完整学习历史，属个人数据
- 仓库**不含**任何密钥、令牌、证书
- 词库中的 `token`（代币）、`secret`（company secretary）是金融词汇，非敏感信息
