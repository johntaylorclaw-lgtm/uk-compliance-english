第二步：今天的音素自测（5 分钟，3 组、16 个）

今天三组音各打一个具体靶子：第 ① 组 = 词尾的 -s 与 -ed 到底读清还是读浊——制裁场景里 sanctions / listed / designated / facilitated 全靠词尾区分；第 ② 组 = 缩写怎么念，今天词表里堆了 FCA / PRA / SFO / CPS / EAR / ITAR / AIS / POCA，念错一个缩写，整句话别人就跟不上；第 ③ 组 = 长词重音，今天有 ownership / consolidated / economic / extraterritorial / circumvention 这些"越长越容易重音跑偏"的词。

单词 / 对照你的读法（先自己读）正确读音你要注意的点
① 词尾 -s 与 -ed —— 清浊之分，以及 -ed 的三种读法
sanctions先自己读一遍再对答案/ˈsæŋkʃnz/词尾是浊音 /nz/：前面 /n/ 是浊辅音，所以 -s 读 /z/。读成 /-ns/ 就把复数听成了另一个形状
listed → designated—/ˈlɪstɪd/ · /ˈdezɪɡneɪtɪd/原形词尾是 /t/ → -ed 读 /ɪd/，多出一个音节。consolidated / facilitated / designated 全是这一类
flagged—/flæɡd/原形词尾是浊辅音 /ɡ/ → -ed 只读 /d/，不加音节。读成 /ˈflæɡɪd/ 是典型中文腔
designate → designated—/ˈdezɪɡneɪt/ → /ˈdezɪɡneɪtɪd/加 -ed 重音不移动，仍在首音节。这一条今天会反复考
② 缩写怎么念 —— 逐字母 vs 读成词，两套规则并存
FCA / PRA / SFO / CPS—/ˌef siː ˈeɪ/ · /ˌpiː ɑː ˈeɪ/ · /ˌes ef ˈəʊ/ · /ˌsiː piː ˈes/逐字母读。这四个是今天的机构名，念错就要重来。FCA = 金融行为监管局，PRA = 审慎监管局，SFO = 严重欺诈办公室，CPS = 皇家检察署
ITAR / OFAC / POCA—/ˈaɪtɑː/ · /ˈəʊfæk/ · /ˈpɒkə/读成一个词。POCA 逐字母念出来，会立刻被听出是新来的；OFAC 的首音是英式 /əʊ/，不是美式 /oʊ/
EAR—/ˌiː eɪ ˈɑː/逐字母。同一批文件里 EAR 逐字母、ITAR 读成词——这就是实务，靠记，不靠推理
AIS / UWO—/ˌeɪ aɪ ˈes/ · /ˌjuː dʌbəljuː ˈəʊ/逐字母。AIS 今天会在"暗船队"里反复出现；UWO 是财富来源不明令
③ 长词重音 —— 越长越容易跑偏
ownership—/ˈəʊnəʃɪp/重音在首音节；英式 /əʊ/ 从 /ə/ 滑向 /ʊ/，不是美式 /oʊ/
consolidated—/kənˈsɒlɪdeɪtɪd/重音在第二音节 -SOL-，前后全是弱读。今天全天第一高频词
economic—/ˌiːkəˈnɒmɪk/重音在 -NOM-；而 economy 却是 /ɪˈkɒnəmi/。同一词根、重音不同，这是今天最典型的错位
extraterritorial—/ˌekstrəterɪˈtɔːriəl/重音在 -TO-，前面四个音节一路滑过去，中间不许停顿
circumvention—/ˌsɜːkəmˈvenʃn/重音在 -VEN-，词尾压成 /ʃn/，不要拖着读成 /ʃən/
voluntary—/ˈvɒləntri/英式习惯读三音节 /ˈvɒləntri/，不是清清楚楚四个音节的 /ˈvɒlənteri/
