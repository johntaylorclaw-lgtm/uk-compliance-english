任务 A：用精讲词写 5 句（15 分钟）

从今天 30 个精讲词里选词，每句至少用 2 个，写成你在真实工作中会说的话。写完朗读一遍，读着拗口的句子必须改到顺为止。今天特别要求：至少 2 句里要用上 export 或 transfer 的名词形式——把重音在前这件事写进句子里感受一次。

示例（可以直接沿用句式）

· Catch-all control is a duty: we assess the end-use whether or not a licence is listed.
· A one-line attestation is not an end-use statement, and it does not cover the price cap.

任务 B：写出「装货前制裁与出口管制审查备忘」四行骨架（10 分钟）

昨天写的是「筛查命中处置记录」，管的是一个名字；今天这份管的是一条船加一批货。四行结构固定，改的只是内容——以后你每一次放行或拦截，留痕都用这个格式。

PRE-LOADING SANCTIONS & EXPORT CONTROL NOTE（骨架，照抄格式，内容用自己的话）
Vessel: [Panamanian-flagged bulk carrier]; registered owner in [Dubai]; AIS dark for [eleven] days before ship-to-ship transfer; charterer's explanation for the gap is not corroborated.
Cargo: Declared as "industrial measuring equipment"; several line items close to dual-use categories under the EAR; no ECCN on file, so catch-all control applies.
Material gap: Ownership chain stops at the second holding company — no UBO, so the ownership and control test cannot be run. The only end-use statement on file is one line long, and no price cap attestation from the charterer.
Decision: Loading instruction frozen; disclosure file opened; no contact with the charterer pending the ownership picture. Exposure if the match is true: strict liability, mitigated by an early voluntary self-disclosure.
为什么今天要把「Exposure」写进最后一行：昨天的四行止于"决定"，今天多写一句后果与减责路径——这是把记录从"操作留痕"升级成"给管理层看的东西"。「no contact with the charterer（不接触承租人）」和「disclosure file opened」是制裁场景里的两个固定动作，写进去说明你知道该防什么。

下一步（如果时间够，把这份补成一页）：主体（Vessel / Cargo / Counterparties）→ 证据（AIS 记录、注册证书、单证清单）→ 结论（Potential or true match；管制结论）→ 后续动作（解锁条件、责任人、时限）。今天先写四行就够，Day-06 补成整页。
