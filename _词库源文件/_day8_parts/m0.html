第二步：今天的音素自测（5 分钟，3 组、16 个）

今天三组音各打一个靶子：第 ① 组 = /ɜː/ 与 /ɔː/ 与 /ɒ/，今天的 personal / controller / processor / disclosure 全踩这三个音，而 costs / costs and charges 里的 /ɒ/ 是英式专属；第 ② 组 = /ʃ/ 与 /tʃ/ 与 /dʒ/，今天的 notification / rectification / subject access request 是重灾区；第 ③ 组 = 词尾 -tion / -sion / -ture 的读法——今天这个词表最大的特点是名词全是 -tion 结尾，而它们的重音位置各不相同。

第 ③ 组做错 3 组以上 → 你的问题不是「单词量」，是「重音在词尾的词怎么建模」。今天词表里 notification / categorisation / erasure / rectification 这类词，重音都在最后或倒数第二个音节——和 Day-04 的 -TION 在中间、Day-06 的 -GA- 在第四音节都不一样。纠正方法：读这些词时把重音那一拍拉长、后面的音节快速带过，用节拍把重音钉在词尾。这批词在 B 段会议里全是关键词——听不出来整段就废了。
