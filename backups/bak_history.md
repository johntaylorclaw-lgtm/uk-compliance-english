### 四、复用 Day-07 脚本时踩的坑（已写入 README）

1. `sed` 会把注释里的行号区间改坏（`701–800` → `701–700`），**注释也是校验线索**，必须逐个复核。
2. `const DAY = 7` 不会被 `day07→day08` 的 sed 命中（它是纯数字），必须手工改。
3. `_build_dayNN.js` 的 CSV 文件名 `词表-Day07.csv` 不会被 `day07` 命中（大小写不同），漏改会**生成错误文件名**。
4. `_verify_dayNN.js` 的 `EXP_TOTAL` 取决于当天 LISTS 的实际条数，不是固定值——本日为 141 而非 136。
5. Page builder 从 Day-07 复制时会**继承术语测的 CSS 与脚本**，需显式 `dropStyle` 并在自检里查`quizTbl` / `QUIZ_ANS` / `class="qin"` 等残留。
6. 模块 05 里刻意写的跨日引用（如 `Day07_合规档案封面备忘_八段.md`）会被自检误判为残留——**合法跨日引用要从残留名单里排除**，否则会误报失败。
